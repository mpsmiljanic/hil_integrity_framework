# hil-integrity-framework - API Specification (v1.0.0)

## 1. Overview

This document defines the formal interfaces and API specifications for the HIL Integrity Framework, including UART telemetry formats, ALSA audio stimulus parameters, and Pytest fixture interfaces.

---

## 2. UART Control Plane Interface

### 2.1 Serial Bus Configuration
* **Port:** `/dev/ttyACM0` (or USB-CDC Virtual COM Port)
* **Baud Rate:** 115200 baud
* **Data Bits:** 8 bits
* **Parity:** None (8N1)
* **Stop Bits:** 1 bit

### 2.2 Telemetry Packet Format
The DUT emits structured ASCII strings over UART whenever valid audio frames are processed by the DSP task:

```text
I2S_TELEMETRY: Samples: <int>, Peak: <int>, RMS: <uint>, Freq: <uint> Hz
```

#### Field Definitions
* **`Samples`:** Number of 32-bit DMA frame samples processed in the buffer (Default: 1023/1024).
* **`Peak`:** Absolute peak amplitude measured in LSB units ($0 \text{ to } 32767$).
* **`RMS`:** Root Mean Square energy calculated over the buffer ($\sqrt{\frac{1}{N}\sum x_i^2}$).
* **`Freq`:** Fundamental signal frequency in Hz estimated via Schmitt-trigger zero-crossing analysis.

#### Regular Expression for Pytest Validation
```python
r"I2S_TELEMETRY: Samples: (\d+), Peak: (\d+), RMS: (\d+), Freq: (\d+) Hz"
```

## 3. Data Plane Audio Stimulus Specification

### 3.1 PCM WAV File Format
Synthetic test audio files generated by Pytest (`generate_sine_wave_wav`) adhere to the following PCM parameters:

* **Encoding:** 16-bit PCM (Signed 16-bit Little Endian)
* **Channels:** Mono (1 channel)
* **Sample Rate:** $44100\text{ Hz}$
* **Frame Slot Width:** 32 bits (dynamically mapped by ALSA `plughw:2,0` overlay)
* **Standard Duration:** $1.5\text{ s}$ (ensures ALSA clock lock stability)

## 4. Pytest Fixture APIs (`conftest.py`)

### 4.1 `serial_connection`
* **Scope:** `module` / `function`
* **Description:** Initializes and opens the serial port to the DUT, flushes input buffers, and manages teardown.
* **Return Type:** `serial.Serial` instance.

### 4.2 `play_audio_and_get_dsp_telemetry(serial_connection, wav_path, timeout=3.0)`
* **Description:** Spawns an asynchronous `aplay` background process via `subprocess.Popen()` and concurrently samples UART serial lines for `I2S_TELEMETRY` matches.
* **Returns:** `dict` containing parsed telemetry fields:
  ```python
  {'samples': int, 'peak': int, 'rms': int, 'freq': int}
  ```
  or `None` on timeout.
